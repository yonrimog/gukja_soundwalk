# 국자와 주걱 사운드워크

Leaflet 지도와 GPS 위치를 이용하는 7개 지점 사운드워크입니다. 이전 프로젝트의 파일이나 음원은 포함하지 않았습니다.

## 음원 넣기

`audio` 폴더에 아래 이름으로 MP3 파일 7개를 넣어 주세요.

- `1.mp3` — 1. 국자와 주걱
- `2.mp3` — 2. 죽은 나무
- `3.mp3` — 3. 흙집
- `4.mp3` — 4. 흙집 다음 좌회전
- `5.mp3` — 5. 사거리 좌회전
- `6.mp3` — 6. 남천 사거리
- `7.mp3` — 7. 마지막 사거리

파일명은 코드의 경로와 정확히 일치해야 합니다. 음원 파일은 제공되지 않아 이 패키지에 들어 있지 않습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 `index.html`, `README.md`, `audio` 폴더를 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` / `/ (root)`를 지정한 뒤 저장합니다.
5. 배포된 HTTPS 주소를 휴대전화에서 엽니다. 위치 권한을 허용해야 GPS가 작동합니다.

## 테스트

- 지도와 7개 지점 표시는 음원 없이도 확인할 수 있습니다.
- 실제 GPS는 HTTPS 환경에서 테스트해 주세요. 로컬 파일(`file://`)로 열면 위치 기능이 제한될 수 있습니다.
- GPS 시작 후 1번부터 순서대로 지점에 접근하면 해당 음원이 재생됩니다.
- 다음 지점에 진입하면 앞 음원은 2초에 걸쳐 페이드아웃된 뒤 다음 음원으로 넘어갑니다.
- 이미 통과한 지점은 다시 트리거되지 않습니다.
- 음원 일시정지 버튼으로 일시정지하고 다시 재생할 수 있습니다.

## 지점과 반경

모든 지점의 진입 반경은 20m입니다. 좌표는 제공된 도·분·초 값을 십진수 위경도로 변환해 코드에 반영했습니다.

지도 타일은 OpenStreetMap을 사용하며, Leaflet 라이브러리는 CDN에서 불러옵니다. 따라서 지도와 라이브러리를 사용하려면 인터넷 연결이 필요합니다.
